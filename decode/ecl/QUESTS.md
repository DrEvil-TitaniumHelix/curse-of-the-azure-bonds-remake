# QUESTS — Curse of the Azure Bonds: quests and commissions in ECL memory (W5, cab-ecl-quests)

Which ECL memory cells record that a quest is **offered**, **accepted**, **progressing**, **done** and **rewarded**, with
the instruction that writes each state. Sources: the 25 decoded scripts in [scripts/](scripts/INDEX.md) (instructions
and semantics: [ECL_VM.md](ECL_VM.md)) and [FLAGMAP.md](scripts/FLAGMAP.md) (every writer and tester of every cell,
generated by `decode/tools/flagmap.py`). Machine-readable form: `game/plus/quests/table.js` (profile `cab`; same ids,
cells and addresses; the Quests tab reads it).

**No game text is written here.** A text is named by `ECLn_RR ADDR` = data set n, block RR, VM address of the PRINT /
PRINTCLEAR instruction (`ECL3_18 95EE` = data set 3, block 18, PRINTCLEAR at 95EE). The Quests tab decodes the text from
the player's own `ECLn.DAX` at run time. Ids (`moander`, `dagger-falls`, ...) are our technical handles, named after a
person or place the cited text names.

Notation: `W addr := v` = SAVE / ADD / SUBTRACT destination (ECL_VM.md §4.1); `T addr = v` = COMPARE operand; `I` =
implicit engine write of an opcode (FLAGMAP kinds). Values are words. Confidence: **H** = the write and the cited text
sit on one straight-line path, or the scripts test the cell with an unambiguous meaning; **M** = the meaning follows from
tests / ordering but a step is inferred; **L** = a guess (none is used by the table). **4C00..4C1F and 7F79..7F82 are
block-local** (`ecl_InitVM` zeroes them on every block load unless a save is resumed, ECL_VM.md §3.3): they cannot
carry a quest across blocks or saves. All cells below are outside those ranges unless said so.

## 1. The main quest: the bonds

### 1.0 How the scripts track it
There is **no "bond removed" cell.** Each chapter ends with a write of its own completion cell, and the hub script counts
them:
- **The grey-robed man (ECL1_80, scene from 81EA):** `W 7F79 := 0` (8232), then `+1` for each of `T 4C59 = 1` (8238),
  `T 4C5B ≠ 0` (8248), `T 4C5A = 1` (8258); PRINT 826C / 8296 tell the count; **`T 7F79 = 3` (828B) → 83CF**, the
  reveal that opens the last chapter (texts 83CF, 83F5, 841F). His directions (8354..83C7) skip each chapter that is
  done: PRINT 8365 unless `4C59 = 1`, PRINT 8389 unless `4C5B ≠ 0`, PRINT 83B1 unless `4C5A = 1`. H.
- **The picture tint cell 4CFF** is written at the bond scenes (W 4CFF := FFh / 1). It is not a quest cell: the engine
  reads it to tint every picture red and to auto-advance the encounter animation (ECL_SCREENS ECL-09, HorizontalMenu
  6800:0507), and no script tests it (FLAGMAP). The table follows those scenes by their text address (a mark).
- Which bond each chapter removes is stated by the cited texts only where listed below; it is not inferred elsewhere.

### 1.1 `tilverton` — the Fire Knives' hideout (ECL2_04) — H
- Texts: 830B (meeting the Fire Knives' leader), 839A (after the fight that follows; the combat loop at 838E..8396
  repeats until it is won), 83F6 (freeing Giogi).
- **Done: `W 4C2A := 1` at ECL2_04 842F**, on the same straight path after 83F6 (journal entry 53 printed at 8429).
  Tested by ECL2_03 (8042, 8155, 81A9, 82BC, 96E5: `T 4C2A = 1`). H.
- Which bond, if any, this chapter removes: **unknown** (no text at these sites names a bond; the tint write at 83E6 sits
  between journal entry 54 and the freeing scene).

### 1.2 `moander` — Yulash and the temple of Moander (ECL3_16..18, "green" in the directions) — H / M
- Direction: ECL1_80 8389. Bond scene: ECL3_18 9581, 95A6 (the bond of Moander fades), tint `W 4CFF := FFh` at 95E5,
  95EE (the sigil disappears). H for the scene.
- **Done: `W 4C5B := 1` at ECL3_18 98AE**, right after PRINTCLEAR 987B (the Gauntlet of Moander found). H.
- **`W 4C5B := FFh` at ECL3_17 84E7**, followed by `W 7F12 := 1` and NEW_ECL 51h (leaving to data set 1). 84E7 is
  reached from three tests at the west exit (82F9 `T 4C5B = FFh`, 8323 `T 4C2E = 0`, 834F after the companion loop),
  not only after 98AE. The hub counts any value ≠ 0 as done. So FFh = "left Yulash by that exit" (M); whether it can
  happen before 98AE in play: **unknown**.

### 1.3 `zhentil-keep` — Zhentil Keep and Fzoul's bond (ECL4_32..37, "black") — H
- Direction: ECL1_80 83B1. Bond scene: ECL4_34 831A / 8344, tint `W 4CFF := FFh` at 8365, **836E (the bond of Fzoul
  fades)**, 838A. H.
- **Done: `W 4C5A := 1` at ECL4_34 8C8E**, right after PRINTCLEAR 8C4E (the Amulet of Lathander retrieved). H.
  Tested in ECL1_80 / ECL1_81 (inns, the Zhentil patrol 9835, the officers 8E95, the sealed city 8324) and ECL3_16.

### 1.4 `dracandros` — Dracandros (ECL5_48..53, "red") — H / M
- Direction: ECL1_80 8365. Scene: tint `W 4CFF := 1` at ECL5_51 8415, PRINTCLEAR 841E (Dracandros' phrase makes the
  bonds fade) and the menu at 8452. Whether that scene is the permanent loss of one bond: M (the hub counts only 4C59).
- **Done: `W 4C59 := 1` (and `W 4C60 := 1`) at ECL5_51 8FB6**, after the combat at 8F82 is won (`T 7EC7 > 80h` at 8F83
  repeats it) and PRINTCLEAR 8F8E (the Helm of Dragons). H.

### 1.5 `tyranthraxus` — the last chapter (ECL6_64..69) — H
- **Offered:** the reveal ECL1_80 83CF, reached only when the count of §1.0 is 3. H.
- Scene: ECL6_67 8963 / 8988 / 89B2 (the bond's control fades, his sigil stays). H.
- **Done: ECL6_67 93E7 `PROGRAM 8`**, after the final combat 93DB is won (`T 7EC7 > 80h` → 93BE again). PROGRAM 8 runs
  the finale (EndSequence, COMBAT_SCREENS COMBAT-18: the final bond fades) and sets **`I 4CFD := FFh`, `I 7EA8 := FFh`**
  (ecl_cab op38, ECL_VM.md §3.3). These engine writes do not go through ecl_SetMem, so no `flagSet` reports them; the
  table reads 4CFD when a save is loaded. H.
- Related, meaning unknown: ECL6_67 93BE `W 7F71 := Mem[4CBB]` before that combat, 4CBB written in ECL6_64 (8ADD := 2,
  8B3F := FEh, after 8A91). The table does not use it.

## 2. `dagger-falls` — the march on Dagger Falls, the keys to the city (ECL1_81) — H / M
- The encounter is skipped once `4C86 ≥ 1` (ECL1_81 9019).
- **Offered:** PRINTCLEAR 90E4 (Zhentil troopers take the party for mercenaries; journal entry 36 at 9141), menu 914B. H.
- `W 4C86 := 1` at 928D (ATTACK: the bugbears and worgs join the fight, 925E) and at 92D7 (after the combat of
  "attack the leaders", 92C0). M (1 = the party fought; the outcome is decided by the next test).
- **Rewarded: `W 4C86 := 2` at 93DF**, right after PRINTCLEAR 938E (the keys to the city and the feast), on the path
  92EC → 92F2 (reached by SLIP AWAY, or when the fight at 92C0 is not won: `T 7EC7 > 80h` at 92DD, the same test that
  repeats a lost fight in the chapter scripts). H. ECL1_80 tests `4C86 = 2` (87C2, 894D; at 894D it skips the
  surly-patrons scene 8963).
- **`W 4C86 := 3` at 94C2** (MARCH ON TESHWAVE, text 9468: both armies routed). H for the write; the table shows it as
  closed.

## 3. `magistrate-daughter` — the drow raid (ECL5_53) — M
- Counter **4C21** in ECL5_53 8A7E..8D74: `T 4C21 > 3` (8A8D) skips the encounter; else `+1` (8A98) and
  `ON_GOTO [4C21], #05` (8AA1; index x jumps to target x+1, ECL_VM.md §4.1) picks the stage: 1 → 8AB6 (a dying man
  asks you to save the magistrate's daughter, text **8AC5 = offered**), 2 → 8B3F (the drow rear guard, 8B4C), 3 → 8BCE
  (the main force, 8BE1), 4 → 8CDD (the girl and the black dragons, 8CE4). A fight that is not won steps back (`-1` at
  8C71, 8D41).
- **Rewarded:** PRINTCLEAR 8E20 (taken back to the surface, the father pays; TREASURE 8EB1) — no cell is written; the
  table marks the text. Declined: 8EC8. Devoured: 8EFF (failed).
- **Carry-over:** 4C21 is also `W := 1` at ECL2_04 82D1 (captured by the Fire Knives) and nothing clears it. With 1
  carried in, the first ECL5_53 visit computes 2 and skips the dying man's scene. M (from the code; not observed in
  play). So the table uses marks for offered / rewarded / failed and the counter only for `≥ 2` (progress), which a carried-in 1
  never meets.

## 4. `filani` — the sage Filani (ECL2_01) — H for the texts, no persistent cell
- PRINTCLEAR 8E9C (she asks about the sigils), 8EDB (her fee), menu 8F21. TELL THE TRUTH: `ROB #01, #32, #00` (8F4D),
  `W 4C13 := 1` (8F54), PRINTCLEAR 8F5A (she talks; journal entry 38 at 8F68). LIE: 8F7C (sent out).
- 4C13 and 4C10 are **block-local**, so nothing records the visit after the party leaves the block. The table marks
  8E9C (offered) and 8F5A (done) as Plus state per save slot.
