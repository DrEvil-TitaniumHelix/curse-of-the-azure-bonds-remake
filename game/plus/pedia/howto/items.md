# Items and identification

An item has a type, up to three name words, a weight and a count. The type sets the rules: which slot it uses, how
many hands, weapon damage. A single item can add a bonus or a power of its own.

Some name words stay hidden until the item is identified. The pedia keeps them hidden as well and shows no bonus or
value for an unidentified item. An item with no visible word is listed as unidentified.

An item type appears together with the first item of that type you see, named after that item's first visible word.
