# JOURNAL_REFS — every "journal entry N" the scripts print (cab-ecl, 2026-10-20)

Input for the Gold Box Plus Journal tab (`docs/PLUS_LAYER.md`): the paper Adventurer's Journal is not in the data
files; the scripts only cite its entry numbers. Source: `decode/ecl/scripts/ECL<n>_<rec>.ecl.txt` (generated by
`decode/tools/ecldis.py --all`); addresses are VM addresses (record byte 2 = 8000h). "shared sub" = the text
" AND YOU RECORD IT IN JOURNAL ENTRY " is a GOSUB subroutine; the entry number is printed by the caller right after
the GOSUB, so the reference address is the caller's PRINT of the number. H for every row (the bytes are in the
listings); the scene column is the preceding PRINTCLEAR text, abbreviated.
