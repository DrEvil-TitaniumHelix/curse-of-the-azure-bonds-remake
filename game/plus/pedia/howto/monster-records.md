# Reading monster records

A monster entry is a template read from your imported game files. The numbers are the starting values the template
holds: level or hit dice, record hit points, base armour class, base THAC0, attacks and base damage. Armour, magic and
effects in a fight can change the values the game actually uses, so treat them as a starting point.

Some fields of a stored template are left-overs (old pointers, counters); the pedia does not show them. Item and effect
lists come from the records with the same number in the matching data set.

The same name can appear in several data sets with different numbers. Those stay separate entries. A combat icon is
attached only after an encounter has shown it.
