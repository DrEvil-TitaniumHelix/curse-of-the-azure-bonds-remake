# VIEW — screens, menus and messages (lane cab-mod-eclview)

Coordinates are text cells (8x8 px) of the 320x200 screen: row 0..24, col 0..39. Routines: decode/pseudo/VIEW.pas.md. Colours are EGA indices. "Menu" = HorizontalMenu 6800:03D4 on row 24 (prompt colour / text colour / hotkey-and-selection colour as passed by the caller; ExploreCommand passes 0Dh / 0Ah / 0Fh). Generic menu keys: hotkey letter (capitals and digits of an option), `,` / `.` move the highlight, Enter = the highlighted option's letter (6800:0640), Esc = cancel (#0), Space = #32, extended keys and keypad digits 1..9 when the caller allows them. A menu timeout (`menu_Timeout`) returns `menu_TimeoutKey`.
