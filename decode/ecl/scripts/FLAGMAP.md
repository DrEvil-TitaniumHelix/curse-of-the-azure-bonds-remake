# FLAGMAP — Curse ECL script memory: who writes and who tests which cell (cab-ecl-quests)

Generated by `python -I decode/tools/flagmap.py` (regenerate, do not edit) from the 25 ECL records (`decode/bin/dax/ECLn/R.bin`, the same records as the listings here), decoded with `ecldis.py` (operand reader and traversal from the five header vectors, ECL_VM.md §2) and classified by the handler semantics of ECL_VM.md §4. Kinds: **W** written (SAVE / arithmetic / RANDOM / INPUT / menu / GET TABLE / AND / OR / SAVE TABLE / PARLAY / PARTYSTRENGTH / CHECKPARTY / PARTY SURPRISE / SPELL destination; `W=$xx` = SAVE of a constant, `W=str` = SAVE of a text, `W+[idx]` = SAVE TABLE with a variable index), **T** tested (COMPARE, COMPARE AND, AND / OR operand; `T=$xx` = compared with that constant), **R** read as a value, **I** implicit engine write by the opcode (NEW ECL, LOAD FILES, SETUP MONSTER, SURPRISE, DIVIDE, PROGRAM 8), **K** CHECKPARTY key. A site is `address:kind`. Roles: the names of ECL_VM.md §3 (via `ecldis.ADDR_NOTES`); *script state* = only the scripts use the cell. **4C00..4C1F and 7F79..7F82 are block-local** (`ecl_InitVM` zeroes them on every block load unless a save is resumed, ECL_VM.md §3.3), so the same cell in two scripts is not shared state; the other script cells of regions 0..2 are saved with the game and persist across blocks: these are the quest flags. Regions 3 (script bytes) and 4 (engine) are counted only. Cross-check: `flagmap.py --check` finds every SAVE / arithmetic / AND / OR destination in regions 0..2 as the last operand of the same instruction in the listings, and no other (2250 = 2250 sites at generation).
