# W3 / S3 — clickability checklist (Curse of the Azure Bonds) — cab-build-engine, 2026-10-21

Rule (PLUS_LAYER.md §1): every mouse action becomes exactly the keys a keyboard player would press. Left click = the
default entry; right click = a modern list (GBP-6) of the keyboard actions at that spot, plus the waiting bottom menu's
commands and "Back (Esc)". Original mode (`?plus=0` / "Play the original game"): the engine's own mouse layer only
(left click = the key of the region, right click = Esc).

**cab.js** the Curse providers), mounted by `game/engine/main_cab.js` (`mountClickLayer({ profile: 'cab' })`).
Unit tests: `node --test game/test/plus/click_cab.test.mjs` (4/4: roster keys, path, roster region, walker).
