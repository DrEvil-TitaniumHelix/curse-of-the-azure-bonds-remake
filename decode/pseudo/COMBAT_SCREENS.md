# COMBAT — screens, menus and messages (lane cab-mod-combat)

Coordinates are text cells (8x8 px) of the 320x200 screen: row 0..24, col 0..39. Routines: decode/pseudo/COMBAT.pas.md. Colours are EGA indices; `DrawText(col, row, fg, bg, s)`, `DrawWrappedText(x1, y1, x2, y2, fg, bg, clear, s)`. "Menu" = HorizontalMenu (prompt colour / text colour / hotkey colour as passed; the combat units pass 13 / 10 / 15 unless noted). Character messages (`ShowCharacterMessage` ShowCharacterMessage(c, msg, row, wait)) print `<name> <msg>` in the combat text window (cols 23h..26h in combat, col 1.. out of combat) on the given row; `ShowTimedBottomMessage` ShowTimedBottomMessage prints on row 24 and waits the message delay; `ShowCombatMessageAnimation` ShowCombatMessageAnimation(c, flag, msg) prints the message and plays the hit/effect animation on the combatant. Combat view layout (VIEW-06): the 7x7 field on the left, the roster/message window on the right (col 23h), the menu row 24, the "Range =" line on row 23 (col 0).
