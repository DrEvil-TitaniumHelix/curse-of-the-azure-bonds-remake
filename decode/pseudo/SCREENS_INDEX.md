# SCREENS_INDEX — master screen inventory of Curse of the Azure Bonds v1.0 (lane cab-crossref, cab-rt / Opus)

Input for BUILD_PLAN.md (gate item 7): one row per distinct screen or screen state the player can see, in game-flow
order. Every row names its source row in `decode/pseudo/<AREA>_SCREENS.md` (with the routine address; the pseudocode
is in `<AREA>.pas.md`) and carries that row's full text, layout, pictures, keys and transitions, so the screen can be
rebuilt from this file plus the conventions below. Generated by `python -I decode/tools/screens_index.py` (rows,
stable ids S001.., transitions rewritten to stable ids, gap checks); the head and the Consistency section are
written by hand. Sources: RESIDENT-01..18, ENGINE-01..33, ECL-01..09, VIEW-01..13 (+02a), PARTY-01..18,
MAGIC-04/08/15/22-nn, COMBAT-05/07/09/13/18/19/23-nn = **167 rows**, every source row placed exactly once.

## 0. Common conventions (apply to every row)

- **Screen**: 320×200, 16 colours on EGA (curse.cfg line 1 `E`; `T` Tandy, `C` CGA 4 colours — RESIDENT-05,
  StartupConfiguration 020F). Text = 40×25 cells of 8×8 glyphs from **8X8D1.DAX record 201 (C9h)** (RESIDENT res_0542),
  cells (col,row) 0-based. Every text routine takes **fg and bg** (resident note #1): `DrawText(col, row, fg, bg, s)`,
  `DrawWrappedText(x1, y1, x2, y2, fg, bg, clear, s)`.
- **Colours** (EGA index): 0Ah light green normal text, 0Bh light cyan party names, 0Ch light red inactive names,
  0Dh light magenta prompts, 0Eh yellow (NPC / enemy names, warnings), 0Fh white (headings, selection, hotkeys)
  (DrawCharacterName 6200:18F3 colours: inactive 0Ch, side 1 = 0Eh, else 0Bh).
- **Frames / layouts**: DrawScreenFrame 01A0:0000 and the layout routines 01A0:00D3/0136/0252/0292/0397/048D
  (RESIDENT-03): full-screen border; picture box (2,2)-(14,14) with the column-16 divider (3D view / pictures 88×88
  at cell (3,3)); roster (17..38, rows 1..15; PARTY-13 PartySummary); text window (1,17)-(38,22) (ECL region table);
  menu line row 24; combat: map window cols 0..22 + side panel 23..38 (VIEW-06, PARTY-14).
- **Menu line** (HorizontalMenu 6800:03D4): row 24, `prompt` in the prompt colour (13), options in the text colour
  (10), hotkeys = every capital letter / digit of the option string (ParseOptions set cs:00B5) and the selected
  option in the hotkey colour (15). Keys: a hotkey, `,` / `.` move the highlight, Enter = the highlighted option,
  extended keys returned with `ext` set (Home/End = scan codes G/O for previous / next member in most menus).
  In 2D areas with BIGPIC 121 the city overlay animation runs while it waits (VIEW-13).
- **List menu** (VerticalListMenu 6800:0DF9, VIEW-09), **Yes / No** (AskYesNo 6800:112A, VIEW-10: `prompt` + `Yes No`,
  default No, keys Y / N), **MenuSelect** 2C00:17EA (`~Yes ~No` style, COMBAT-05-06).
- **Messages**: bottom message row 24 (ShowTimedBottomMessage 6200:177A / ShowBottomPromptAndReadKey 0542:0946,
  RESIDENT-18, MessageDelay = GameSpeed × 100 ms); character message (ShowCharacterMessage 6200:17D6, PARTY-16:
  outside combat name at (1,row+1) and text below in the text window, in combat the right panel from row 10);
  full text window -> `Press any key to continue` (RESIDENT-12).
- **Pictures**: DAX records through LoadDaxRecord 0636:08DE and LoadPicture 0297:011B; file names `<NAME><n>.DAX`
  with n = data set DS:5BEE (decode/data/INDEX.md). Portrait / encounter pictures (VIEW-07/08), 3D view (VIEW-01,
  WALLDEF / 8X8D / GEO / SKY), BIGPIC 2D backdrops (VIEW-04), combat icons (CPIC / COMSPR, VIEW-06).
