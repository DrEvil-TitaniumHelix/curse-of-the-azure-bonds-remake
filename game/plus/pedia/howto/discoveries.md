# Discoveries and save slots

The pedia keeps observations for each save slot. Loading another slot changes the discoveries shown. Saving the current party under another letter carries its discoveries into that slot.

Seeing a creature, visiting a place, seeing treasure or learning a spell gives the pedia evidence for an entry. Unseen entries stay out of search results. A nameless encounter does not establish a person's identity, and an unidentified item does not reveal its hidden powers.

The same creature name can belong to different records. The pedia uses confirmed record identities where available rather than treating every matching name as the same creature. Meeting places are attached to the observations actually recorded.

Original-game mode stops new observations. Previously recorded discoveries remain saved. If browser storage fails, new observations stay available for the current session.
